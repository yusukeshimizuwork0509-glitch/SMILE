## 使い方
- フローの更新はPRで。ノード追加は `A --> B` を追記。
- 画面名・ボタン名・担当（担当部署/営業本部/資材部）を**ラベル**に寄せる。
- 例外動線（差戻/不採用/取消）は**別枝**で明示。
